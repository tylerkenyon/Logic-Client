# Logic Client v0.1.2

This release adds Minecraft 26.3 support, faster anchor sequencing, KeyPearl, exact numeric entry, and a smaller Windows native bundle.

- Support Minecraft 26.2 and 26.3 with Java 25, Fabric Loader and Fabric API.
- Embed both versioned Java payloads and their shared runtime in the native DLL. The Windows bundle needs no loose JARs beside the launcher.
- Remove unused native libraries from the Windows x64 payload and increase archive compression. The native DLL is approximately 60% smaller than the previous development bundle.
- Automatically select anchor, glowstone and detonation items from the hotbar. Chain confirmed anchor stages, restore the original slot once at the end, and configure independent min/max swap, interaction and restore delays.
- Add Misc > KeyPearl. Assign its module bind to queue one pearl throw with configurable swap, throw and restore delays. Support hotbar and offhand pearls, respect vanilla cooldown, and cancel pending actions when the player changes slots or leaves gameplay.
- Add Ctrl+click numeric entry to settings and sliders. Enter saves, Escape cancels, and a range accepts two endpoints or one fixed value.
- Add Burst, Crit, Combo and Timer Hit Select modes with Triggerbot integration.
- Apply Eagle at the player's movement-input step and account for momentum near edges.
- Improve the protected overlay's window stacking, minimization handling, SDL input and OpenGL/Vulkan compatibility.
- Include randomized combat timing ranges, Freeze Backtrack improvements, client-spoofing options and startup notifications.

Download and extract the Windows ZIP, then run LogicLauncher.exe with logic_native.dll beside it. Restart Minecraft before upgrading the native loader. The loader extracts its embedded runtime into the user's Logic cache during injection.

For Fabric mod installation, download the JAR matching your Minecraft version from this release and install it alongside Fabric API. Mica is bundled.

Existing settings are preserved. Legacy anchor timing and Held item modes migrate to the new settings. Saved custom delays continue to apply.

Verification includes both version builds, settings and configuration checks, injection bytecode checks, Windows packaging checks, and native injection/unload/reinjection smoke tests. Local gameplay checks covered anchor charging/detonation and a single pearl throw. Live Grim-server compatibility remains unverified.
