# Logic Client v0.1.3

This release adds manually saved configuration profiles and improves AimAssist target-point selection.

- Add Configuration > Profiles with Load, Save as, Overwrite, Rename, Delete and Refresh controls. Overwrite and delete require confirmation.
- Autosave the working session to `latest.json` once per second and on normal exit. Startup restores that session; named configs in `configs/` change only when explicitly saved or overwritten.
- Include module settings, enabled states, keybinds, theme and panel layout in snapshots. Apply loads at a client tick boundary, cancel active actions and input editors, and keep the ClickGUI open.
- Validate named configs before applying them, reset omitted settings to registered defaults, and restore previous settings if activation or final-save fails. Show operation errors inside Profiles even when notifications are disabled.
- Improve AimAssist's Closest target-point mode so it follows the view ray, and add an Optimal target-point option.
- Remove legacy configuration conversions. Existing `config.json` files remain untouched and are not imported; this release starts a new working session in `latest.json`.

Minecraft 26.2 and 26.3 remain supported with Java 25. For the Windows injector, extract the ZIP and keep LogicLauncher.exe beside logic_native.dll. Restart Minecraft before upgrading the native loader. For Fabric installation, use the JAR matching your Minecraft version alongside Fabric API; Mica is bundled.

Validation covers both version builds, configuration and profile lifecycle/failure checks, injection bytecode checks, runtime reload checks, Windows packaging checks, and native injection/unload/reinjection smoke tests. The new profile controls have not been manually exercised in a live Minecraft session.
